**Maven** is a powerful build automation and project management tool for Java projects. Think of it as a project organizer that:

- Manages your project dependencies (libraries)
- Builds your code
- Runs tests
- Packages your application
- Follows a standard project structure

## Essential Maven Commands
```bach
# Compile your code
mvn compile

# Run tests
mvn test

# Package into JAR file
mvn package

# Clean build artifacts
mvn clean

# Clean + compile + test + package
mvn clean install
```

## Maven Project Structure
```
my-project/
│
├── pom.xml                          # Project configuration file
│
├── src/
│   ├── main/                        # Application source code
│   │   ├── java/                    # Java source files
│   │   │   └── com/mycompany/
│   │   │       ├── App.java
│   │   │       ├── model/
│   │   │       ├── service/
│   │   │       └── controller/
│   │   │
│   │   ├── resources/               # Application resources
│   │   │   ├── application.properties
│   │   │   ├── config.xml
│   │   │   └── static/
│   │   │       ├── images/
│   │   │       └── css/
│   │   │
│   │   └── webapp/                  # Web application files (for web projects)
│   │       ├── WEB-INF/
│   │       │   └── web.xml
│   │       ├── index.html
│   │       └── css/
│   │
│   └── test/                        # Test source code
│       ├── java/                    # Test Java files
│       │   └── com/mycompany/
│       │       └── AppTest.java
│       │
│       └── resources/               # Test resources
│           └── test-config.xml
│
└── target/                          # Build output (generated by Maven)
    ├── classes/                     # Compiled classes
    ├── test-classes/                # Compiled test classes
    ├── my-project-1.0.jar          # Final packaged artifact
    └── surefire-reports/            # Test reports
```
